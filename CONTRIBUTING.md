# Contributing

## Licensing of contributions

This project is licensed under **AGPL-3.0-only** (from version `2.0.0` — see
[LICENSE-HISTORY.md](LICENSE-HISTORY.md)). By submitting a contribution (a pull
request, patch, or any change) you agree that your contribution is licensed
under AGPL-3.0-only, the same license as the project (inbound = outbound).

Sign off every commit to certify you have the right to submit it under that
license, per the [Developer Certificate of Origin](https://developercertificate.org/):

```
git commit -s
```

which adds a `Signed-off-by: Your Name <you@example.com>` trailer.
